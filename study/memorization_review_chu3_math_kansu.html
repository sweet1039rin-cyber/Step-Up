中3数学 復習｜一次関数（中2） 暗記シート

🔁 復習用｜中2・一次関数（変化の割合・グラフ・直線の式・交点・利用）／ 読んで覚える → 問題で使えるようにしよう

1．一次関数とは

y が x の関数で、y＝ax＋b（a、b は数、a≠0）の形で表せるとき、y は x の一次関数です。比例 y＝ax は b＝0 の場合で、一次関数の仲間です。

y＝ax＋b　→　a＝傾き（変化の割合）、b＝切片

x² の式や、x が分母にある式は一次関数ではありません。

2．変化の割合（最重要）

覚えること：変化の割合
変化の割合 ＝ (yの増加量) ÷ (xの増加量)
  • 一次関数では、変化の割合はいつも a と等しく一定
  • x と y の組が2つ分かれば、式がなくても差どうしのわり算で出せる
  • 例：x が －2→3（増加量5）、y が －7→8（増加量15）→ 変化の割合＝15÷5＝3

3．グラフのかき方・読み方

覚えること：グラフと a、b の関係
  • b（切片）：グラフと y 軸の交点の y 座標。まずここに点を打つ
  • a（傾き）：右へ1進んだときに上下する量。a＞0 → 右上がり、a＜0 → 右下がり
  • かき方：切片の点 → 傾きの分だけ「右へ・上下へ」動かした点 → 2点を直線で結ぶ
  • 平行な直線どうしは傾きが等しい
y＝2x＋1 → 切片 1、傾き 2（右へ1、上へ2）

4．直線の式の求め方（3パターン）

覚えること：どのパターンかを見分ける
  1. 傾きと切片が分かる → そのまま y＝ax＋b に入れる
  2. 傾きと通る1点が分かる → y＝ax＋b に a と点の x、y を代入して b を求める
  3. 通る2点が分かる → まず a＝(yの増加量)÷(xの増加量)、次に1点を代入して b を求める
2点 (1,3)、(3,7) → a＝(7－3)÷(3－1)＝2 → 3＝2＋b → b＝1 → y＝2x＋1

平行と言われたら、傾きは相手の直線からそのまま借りる。

5．2直線の交点

覚えること：交点＝連立方程式の解
  • 交点は2つの式を両方成り立たせる点。2式の右辺を等しいとおくか、連立方程式として解く
  • 例：y＝2x＋1 と y＝－x＋7 → 2x＋1＝－x＋7 → x＝2 → y＝5 → 交点 (2, 5)
  • 答えは x＝、y＝ ではなく座標 (x, y) の形で書く
  • x 軸との交点 → y＝0 を代入／ y 軸との交点 → x＝0 を代入（＝切片）

6．利用の型

覚えること：利用は「はじめの量＋変化」
  • 料金：基本料金が b、単位ごとの料金が a。例：y＝180x＋1200
  • 減るもの（ろうそく・水など）：傾きはマイナス。例：y＝－0.5x＋20
  • 「y が ○ になるのはいつ／いくらか」は、y にその値を代入して x を求める
🎯 ここが出る！
  • 変化の割合を、2つの値の組から差で求める問題
  • 2点を通る直線の式（a を出してから b を求める2段階）
  • 平行な直線の式と、2直線の交点
  • 料金・ろうそく型の利用（式を作って代入する）
⚠ 間違えやすい点（ここをチェック！）
  • 変化の割合で、x と y の引く順番をバラバラにする（符号が逆になる）
  • 切片を点の x 座標と取り違える（切片は y 座標）
  • 交点の答えを座標の形で書かない
  • 減っていく問題で、傾きのマイナスを付け忘れる
