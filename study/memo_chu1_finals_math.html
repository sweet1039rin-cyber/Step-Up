期末テスト対策／正式範囲：教科書P88〜129・数学の友P56〜83（当日、定規は不要）

この範囲で学ぶこと

今回の期末テストは、方程式と比例の2本柱です。どちらも「手順どおりに進めれば必ず解ける」タイプの単元なので、解き方の手順 → 例題（途中式）→ つまずき注意の順で身につけるのが近道です。

  1. 等式の性質と方程式：天秤のイメージで「両辺に同じことをしても等しいまま」を理解する
  2. 方程式の解き方：等式の性質で解く方法と、移項で解く方法の2つを使い分ける
  3. 比例式：「外側どうし・内側どうしの積が等しい」で解く
  4. 比例の式とグラフ：y = ax の式を求めることと、原点を通る直線のグラフを読み・かくこと

計算は途中式を省略せず、1行ずつ書くことが大切です。符号のミスは途中式を書けば見つけられます。また、解いた答えはもとの式に代入して確かめる習慣をつけましょう。

1．等式の性質と方程式の基本

図1：方程式は天秤。両辺に同じことをすれば、等しいまま

等式の性質（4つ）
  • 両辺に同じ数を足しても、等しいまま
  • 両辺から同じ数を引いても、等しいまま
  • 両辺に同じ数をかけても、等しいまま
  • 両辺を同じ数でわっても、等しいまま（ただし、わる数は0ではないこと）
  • 方程式：まだ分からない数（x など）を含む等式
  • 解：方程式を成り立たせる x の値。「方程式を解く」とは、この値を求めること
  • 確かめ方：求めた値を x に代入し、左辺と右辺が等しくなれば正解
例題：x + 3 = 7 を解く（性質を使う）

左辺を x だけにしたいので、両辺から 3 を引く。

x + 3 − 3 = 7 − 3　→　x = 4

確かめ：x = 4 を代入すると、左辺は 4 + 3 = 7 で右辺と等しい。だから解は x = 4 で正しい。

📝 テストではこう出る

「等式の性質を使って解きなさい」という指示つきの問題や、解の確かめを問う問題が出ます。両辺に何をしたかを途中式に残すことが大切です。

2．方程式の解き方（移項）

図2：移項＝項が ＝ を飛び越えると、符号が反対になる

解き方の手順（移項バージョン）
  1. 文字の項を左辺へ、数の項を右辺へ集める（移項したら符号を変える）
  2. 左辺どうし、右辺どうしを計算して、ax = b の形にする
  3. 両辺を x の係数 a でわると、x = ○ の形になる
  4. かっこがある式は、先に分配法則でかっこをはずす。小数・分数は、両辺に10や分母をかけて整数の式に直してから解くと楽
例題1：2x + 5 = 17
2x = 17 − 5　→　2x = 12　→　x = 6

+5 を右辺へ移項して −5 にする。最後に両辺を係数 2 でわる。

例題2：5x − 3 = 2x + 9（図2の式）
5x − 2x = 9 + 3　→　3x = 12　→　x = 4

2x を左辺へ（−2x に）、−3 を右辺へ（+3 に）移項する。確かめ：左辺 5×4−3 = 17、右辺 2×4+9 = 17 で等しい。

例題3：x/4 + 3 = 8（分数の係数）
x/4 = 8 − 3　→　x/4 = 5　→　x = 20

先に +3 を移項して x/4 だけを残し、その後に両辺へ分母の 4 をかける。順番を逆にしないこと。

例題4：3(x − 2) = 12（かっこがある式）
3x − 6 = 12　→　3x = 12 + 6　→　3x = 18　→　x = 6

分配法則で 3 を (x − 2) の両方にかける。3×(−2) = −6 の符号に注意。

例題5：0.3x + 1 = 4（小数の式）
両辺を10倍：3x + 10 = 40　→　3x = 30　→　x = 10

小数が出たら、両辺を10倍（または100倍）して整数の式に直すと、ふつうの方程式と同じに解ける。

⚠ つまずき注意（方程式）
  • 移項したのに符号を変え忘れるのが一番多いミス。＝ を飛び越えたら、必ず符号を反対にする
  • 移項しない項の符号は変えない。動かした項だけが変わる
  • 最後の割り算は、両辺とも係数でわる。片方だけわるのは×
  • 分数の係数は「移項してから分母をかける」。x/4 = 5 の次に 4 をかける順番を守る
📝 テストではこう出る

計算問題として何問も並びます。移項の符号ミスと、最後の割り算のし忘れが失点の中心。1行ずつ途中式を書き、時間が余ったら代入して確かめるのが確実です。

3．比例式

図3：比例式では「外側どうしの積 ＝ 内側どうしの積」

a : b = c : d　ならば　a × d = b × c
解き方の手順
  1. 外側どうし（a と d）、内側どうし（b と c）の積を等しくする式を作る
  2. x を含む項を一方に集めて、ふつうの方程式として解く
例題1：x : 6 = 5 : 10
10x = 6 × 5　→　10x = 30　→　x = 3

外側は x と 10、内側は 6 と 5。積を等しくしてから両辺を 10 でわる。

例題2：4 : x = 8 : 14
8x = 4 × 14　→　8x = 56　→　x = 7

x が内側にある場合は、内側の積の中に x が入る。式の形は同じで、外側の積 4×14 と等しくする。

⚠ つまずき注意（比例式）
  • 外側と内側を取り違えるミスに注意。「外×外 ＝ 内×内」と声に出して確認する
  • 比の順番を勝手に入れ替えない。a : b の向きはそのまま使う
📝 テストではこう出る

比例式を解く計算問題と、地図の縮尺や材料の分量などの文章題で出ます。式を作る前に「外側はどれとどれか」を指で押さえるのがコツです。

4．比例の式を求める

y が x に比例する　→　y = ax　（a は比例定数、a = y ÷ x）
式を求める手順
  1. 対応する x と y の組を1つ選ぶ
  2. a = y ÷ x で比例定数を計算する
  3. y = ax に a を入れて完成。他の組でも同じ a になるか確かめると安心
例題1：x = 2 のとき y = 6
a = 6 ÷ 2 = 3　→　式は y = 3x　／　x = −4 のとき y = 3 × (−4) = −12
例題2：表から式を求める
x−3−1025
y620−4−10

x = 5 のとき y = −10 だから、a = −10 ÷ 5 = −2。式は y = −2x。確かめに x = −3 を使うと y = −2 × (−3) = 6 で、表と合う。

例題3：文章題（代金）

ノート5冊の代金は750円。代金が冊数に比例するとして、8冊の代金を求める。

1冊分は 750 ÷ 5 = 150円　→　式は y = 150x　→　8冊では 150 × 8 = 1200円
⭐ 比例の「式とグラフの対応表」
比例定数 aグラフの形x が増えると y は
a > 0（プラスのとき）原点を通る右上がりの直線増える
a < 0（マイナスのとき）原点を通る右下がりの直線減る
  • どちらの場合も、グラフは必ず原点（0, 0）を通る
  • a の絶対値が大きいほど、グラフの傾きは急になる
  • 式が分かれば、x に値を代入して通る点の座標が求まる（例：y = 3x で x = 1 なら点（1, 3））
⚠ つまずき注意（比例の式）
  • a = y ÷ x の割り算の向きを逆にしない。「y わる x」
  • 比例定数が負の数になるとき、符号の落とし物に注意（例題2の a = −2）
  • y = ax の a に、求めた値を必ず代入して式を完成させる。「a = 3」のままで終わらない
📝 テストではこう出る

「x と y の関係を式で表しなさい」と「x = ○ のときの y の値」の2つセットが定番。表から求める場合は、どの組を使っても同じ a になることが確かめに使えます。

5．比例のグラフ（読み取り・かき方）

図4：比例のグラフは原点を通る直線。a＞0 は右上がり、a＜0 は右下がり

グラフから式を求める手順
  1. グラフが通る点のうち、原点のほかに読み取りやすい点を1つ選ぶ（目盛りの交点にある点）
  2. その点の座標で a = y ÷ x を計算する
  3. y = ax に入れて完成
例題1：グラフが原点と点（3, −6）を通る
a = −6 ÷ 3 = −2　→　式は y = −2x　／　x = 5 のとき y = −2 × 5 = −10

点の座標は（x, y）の順。−6 が y、3 が x であることに注意。

グラフをかく手順
  1. 原点（0, 0）に点を打つ
  2. x = 1 のときの y など、もう1点を求めて打つ（y = 4x なら点（1, 4））
  3. 2点を結んで直線を引く（直線は両端を少し伸ばす）
例題2：点がグラフ上にあるか調べる

y = 4x のグラフについて、点（−1, −4）は x = −1 のとき y = 4 × (−1) = −4 となり、座標と一致するのでグラフ上の点。点（2, 6）は y = 8 になるはずで一致しないので、グラフ上の点ではない。

⚠ つまずき注意（グラフ）
  • 座標は（x, y）の順。読み取りで逆にすると a の値が逆数になってしまう
  • 比例のグラフは必ず原点を通る直線。曲線や、原点を通らない直線は比例ではない
  • a が負のときは右下がり。式の符号とグラフの向きが合っているか最後に確認する
📝 テストではこう出る

グラフから式を求める問題と、式からグラフをかく問題が両方向で出ます。当日は定規が不要とされているので、フリーハンドでまっすぐに引く練習をしておくと安心です。

⚠ まとめ｜間違えやすい点（ここをチェック！）
  • 方程式：移項したら符号を変える。変えるのは動かした項だけ
  • 方程式：最後は両辺を x の係数でわる。片方だけは×
  • 方程式：分数は「移項 → 分母をかける」、かっこは「先に分配」、小数は「10倍して整数に」
  • 比例式：外×外 ＝ 内×内。取り違えが一番多い
  • 比例：a = y ÷ x（向きを逆にしない）。求めた a は式に代入して完成させる
  • グラフ：座標は（x, y）の順。比例のグラフは原点を通る直線
  • 計算ミスの発見には代入の確かめ。方程式は解を、比例は別の組で確かめる
