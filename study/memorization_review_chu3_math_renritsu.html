🔁 復習用｜中2・連立方程式（加減法・代入法・利用）／ 読んで覚える → 問題で使えるようにしよう

1．連立方程式の解とは

2つの方程式を両方とも成り立たせる x、y の組が、その連立方程式の解です。求めるものが2つあるので、式も2本必要です。

解の検算 ＝ 答えを 2本とも の式に代入して、両方成り立つか確認

2．加減法（最重要）

覚えること：加減法の手順
  1. 消したい文字の係数の絶対値をそろえる（一方、または両方を何倍かする）
  2. 符号が逆ならたす、同じならひく → 1文字消える
  3. 残った文字を求め、もとの式のどちらかに代入してもう一方を求める
例：2x＋3y＝16、x－2y＝1 → 下を2倍してひくと 7y＝14 → y＝2、x＝5

何倍かするときは、右辺も含めて全部の項を倍にすること。

3．代入法

覚えること：代入法の手順
  1. 一方の式を「y＝（xの式）」または「x＝（yの式）」の形にする（最初からその形ならそのまま）
  2. もう一方の式のその文字に、かっこをつけて代入する
  3. 1文字だけの式を解き、出た値を代入した式に戻して、もう一方を求める
y＝x＋1 を 2x＋y＝10 に代入 → 2x＋(x＋1)＝10 → x＝3、y＝4

選び方：係数が1の文字がある／すでに y＝… の形 → 代入法が速い。それ以外は加減法が基本。

4．かっこ・小数・分数の処理

覚えること：解く前に形を整える
  • かっこ → 先に展開して整理する。例：3(y－1)＝3y－3（中の全部にかける）
  • 小数 → 両辺を10倍・100倍して整数にする。例：0.2x＋0.3y＝1.2 → 2x＋3y＝12
  • 分数 → 両辺に分母の最小公倍数をかける。例：(x/3)＋(y/2)＝4 → ×6 → 2x＋3y＝24
  • A＝B＝C の形 → A＝B と B＝C（または A＝C）の2本の式に分ける

5．利用（文章題）の型

覚えること：文章題は「何を x、y とするか」から
  • 個数と代金：式1＝個数の合計、式2＝代金の合計（単価×個数）
  • 2けたの数：十の位 x、一の位 y → もとの数＝10x＋y、入れかえた数＝10y＋x
  • 速さ：道のり＝速さ×時間、時間＝道のり÷速さ。そろえる量（道のり・時間）で式を立てる
  • 食塩水・割合：式1＝全体の重さ、式2＝食塩の重さ（重さ×濃度、濃度は 6％＝0.06）

答えが出たら、問題文の条件に両方合うか必ず検算する。

🎯 ここが出る！
  • 係数をそろえるために片方を2倍・3倍する加減法（そのままでは消えない形）
  • y＝… の形からの代入法と、かっこ付きの代入の展開
  • 小数・分数を整数になおしてから解く問題
  • 文章題は個数と代金と食塩水が鉄板。2けたの数の 10x＋y も要チェック
⚠ 間違えやすい点（ここをチェック！）
  • 式を何倍かするとき、右辺を倍にし忘れる
  • 代入でかっこを付けず、符号や展開を落とす（3(2y－1)＝6y－3）
  • ひき算で －(－4y) の符号ミス
  • 文章題で答えの単位や聞かれたもの（x、y ではなく「もとの数」など）を取り違える
