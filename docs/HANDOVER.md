# Step Up 引き継ぎ資料

## プロジェクト概要

Step Up は、子ども一人ひとりの学習計画、課題・教材の進捗、成長記録、AIコーチへの学習報告を管理するWebアプリです。`index.html`、`styles.css`、`app.js` を中心に構成され、WindowsではPowerShellサーバー、Linuxでは静的HTTPサーバーで画面を配信します。

## ブランチ

現在の主なブランチは次の2つです。

- `main`
- `v7-development`

## 作業方針

- ユーザーはコードを直接編集しない。
- ChatGPTがVS Code AIチャット用の指示をコード形式で作成する。
- ユーザーは、その指示をAIチャットへ貼り付け、許可、保持、動作確認を行う。
- 画面部品は表示文字だけで判断せず、必ずIDを確認してから修正する。
- 1つの作業を完了してから、次の作業へ進む。

## Git操作の手順

Git操作は、次の順番で必ず1操作ずつ案内する。

1. `git status`
2. `git add`
3. `git commit`
4. `git push`
5. Pull Request
6. Merge

各操作の結果を確認してから、次の操作へ進む。複数のGit操作を一度に実行しない。
